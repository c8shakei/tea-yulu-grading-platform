# W2 M2 对比实验（检测 vs 分类）

> 里程碑：M2 模型训练完成  
> 责任人：W2 视觉模型工程师  
> 日期：2026-09-04  

## 1. 实验目的

为毕业论文提供对照实验，验证"检测模型 + 单图最高置信度框"分级策略的合理性。比较对象：

- **主实验**：YOLOv8n 检测模型（`src/models/train_detect.py`）
- **对照实验**：YOLOv8n-cls 分类模型（`src/models/train_cls.py`）

## 2. 实验设置

### 2.1 数据集同源

两类模型使用同一 TeaLeafAgeQuality 数据集：

- 检测格式：`{split}/images` + `{split}/labels`（YOLO txt）
- 分类格式：由 `train_cls.py` 自动转换为 `{split}/{class_name}/image.jpg`

### 2.2 模型配置

| 配置项 | 检测模型 | 分类模型 |
|--------|----------|----------|
| 基模型 | `yolov8n.pt` | `yolov8n-cls.pt` |
| 任务 | detect | classify |
| 输入尺寸 | 640 | 224 |
| Batch | 16 | 64 |
| Epochs | 100 | 100 |
| 优化器 | AdamW | AdamW |
| 学习率 | 0.001 | 0.001 |
| Patience | 20 | 20 |
| 随机种子 | 42 | 42 |

### 2.3 输出接口

- 检测模型：输出等级 + 置信度 + 归一化 bbox（契约②）
- 分类模型：仅输出 Top-1 / Top-5 类别概率，作为论文对照指标

## 4. 结果分析（待训练完成后补充）

1. **检测模型优势**：可解释性强，能定位茶叶区域，单图存在多片茶叶时仍可取置信度最高框；输出 bbox 可作为溯源图片裁剪依据。
2. **分类模型局限**：需预先裁剪茶叶区域，对拍摄背景敏感；但参数量小、推理更快。
3. **结论预期**：若检测模型 mAP50-95 ≥ 0.90 且与分类模型准确率接近或更优，则证明检测策略在分级任务中同时具备准确性与可解释性。
