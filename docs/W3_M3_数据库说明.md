# W3-M3 数据库说明

## 1. 设计目标

- 使用 **SQLite 单文件数据库**（`data/tea_yulu.db`），便于演示、提交与迁移。
- 存储两类核心数据：
  1. **检测结果**：来自 `/api/detect` 的图像分级信息。
  2. **哈希链区块**：来自 `/api/trace` 的溯源区块。
- 通过 `trace_id` 关联检测记录与溯源链。

## 3. 表结构

### 3.1 detections（检测记录表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| trace_id | TEXT | UNIQUE NOT NULL | 检测唯一标识，同时也是溯源链 ID |
| class_id | INTEGER | NOT NULL | 0 特级 / 1 一级 / 2 二级 / 3 等外 |
| class_name | TEXT | NOT NULL | 等级中文名 |
| confidence | REAL | NOT NULL | 模型/模拟置信度 |
| bbox | TEXT | NOT NULL | JSON 字符串，形如 `[x1, y1, x2, y2]` |
| image_path | TEXT | | 上传图片本地保存路径 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 检测时间 |

**建表 SQL**：
```sql
CREATE TABLE IF NOT EXISTS detections (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    trace_id TEXT UNIQUE NOT NULL,
    class_id INTEGER NOT NULL,
    class_name TEXT NOT NULL,
    confidence REAL NOT NULL,
    bbox TEXT NOT NULL,
    image_path TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_detections_trace_id ON detections(trace_id);
```

### 3.2 blocks（哈希链区块表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| trace_id | TEXT | NOT NULL | 所属溯源链 ID |
| block_index | INTEGER | NOT NULL | 区块高度，链内从 0 开始 |
| timestamp | REAL | NOT NULL | 区块生成时间（Unix 秒，含小数） |
| prev_hash | TEXT | NOT NULL | 前一区块哈希 |
| data_hash | TEXT | NOT NULL | payload 的 SHA-256 |
| hash | TEXT | NOT NULL | 当前区块 SHA-256 |
| payload | TEXT | NOT NULL | 业务 payload 的 JSON 字符串 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 入库时间 |

**联合唯一约束**：`(trace_id, block_index)`，确保同一 trace 内区块高度唯一。

**建表 SQL**：
```sql
CREATE TABLE IF NOT EXISTS blocks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    trace_id TEXT NOT NULL,
    block_index INTEGER NOT NULL,
    timestamp REAL NOT NULL,
    prev_hash TEXT NOT NULL,
    data_hash TEXT NOT NULL,
    hash TEXT NOT NULL,
    payload TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(trace_id, block_index)
);
CREATE INDEX IF NOT EXISTS idx_blocks_trace_id ON blocks(trace_id);
```

## 4. 关系图

```
+-------------+         +----------------+
| detections  |         |     blocks     |
+-------------+         +----------------+
| trace_id (PK)|<------->| trace_id       |
| class_id    |         | block_index    |
| class_name  |         | prev_hash      |
| confidence  |         | data_hash      |
| bbox        |         | hash           |
| image_path  |         | payload        |
| created_at  |         | created_at     |
+-------------+         +----------------+
```

一条检测记录对应一条溯源链（`trace_id` 1:1）。链内可追加多个区块。

## 6. 迁移与备份

- 备份：直接复制 `data/tea_yulu.db`。
- 重置：删除 `data/tea_yulu.db`，重新启动服务即可自动重建空表。
- 不依赖任何 ORM，纯 `sqlite3` 标准库实现，兼容 Python 3.11+。
