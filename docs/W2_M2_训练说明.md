## 4. Colab 训练流程

### 4.1 前置准备

1. 将本地 `D:\BISHE_DATA\datasets\tea_yulu` 整体压缩并上传到 Google Drive：`/MyDrive/BISHE_DATA/datasets/tea_yulu`
2. 将 `src/models/train_detect.py` 上传到 Colab `/content`
3. 新建 Colab Notebook，挂载 GPU 运行时

### 4.2 执行训练

```python
# 安装依赖
!pip install -q ultralytics

# 运行训练脚本
%run train_detect.py
```

脚本将自动：
1. 挂载 Google Drive
2. 拷贝数据集到 `/content/datasets/tea_yulu`
3. 使用 `data.yaml` 训练 `yolov8n` 检测模型
4. 在测试集上评估并保存 `test_metrics.json`
5. 绘制 `training_curves.png`
6. 将 `best_detect.pt` 同步回 Google Drive：`/MyDrive/BISHE/models/best_detect.pt`

### 4.3 方案 B（Drive 受阻时）

若 Google Drive 挂载或拷贝失败：
1. 从 Mendeley Data 页面手动下载原始数据集 zip
2. 在 Colab 单元格执行：
   ```python
   from google.colab import files
   files.upload()
   ```
3. 将上传文件重命名为 `/content/tea_yulu_raw.zip`
4. 重新运行 `%run train_detect.py`

## 5. 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 基模型 | `yolov8n.pt` | 必要时升级为 `yolov8s.pt` |
| 随机种子 | `42` | 保证可复现 |
| 输入尺寸 | `640` | 检测标准尺寸 |
| Batch | `16` | 根据显存可调整 |
| Epochs | `100` | EarlyStopping patience=20 |
| 优化器 | `AdamW` | 收敛稳定 |
| 初始学习率 | `0.001` | 配合余弦退火 |
| 最终学习率 | `0.01 * 0.001` | 余弦退火至 lr0 * lrf |

数据增强：
- HSV 增强：h=0.015, s=0.7, v=0.4
- 平移：0.1
- 缩放：0.5
- 水平翻转：0.5
- Mosaic：1.0
