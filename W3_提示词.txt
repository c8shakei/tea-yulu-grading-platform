【接口契约（你需遵守/提供）】
② 推理封装（消费 W2）：detect()->{class_id,class_name,confidence,bbox}
③ API 契约（你提供）：
- 统一响应：{"code":0,"message":"ok","data":{...}}
- POST /api/auth/register 入参{username,password} 出参{user_id,username,token}
- POST /api/auth/login     入参{username,password} 出参{user_id,username,token}
- GET  /api/auth/me        出参{user_id,username,role}
- POST /api/auth/logout    出参{message}
- POST /api/detect 入参{image} 出参{class_name,confidence,bbox,trace_id?,user_id?}
- POST /api/trace  入参{payload} 出参{block_index,hash,prev_hash,timestamp}
- GET  /api/trace/{id} 出参{chain:[...]}
- GET  /api/detections     出参{detections:[...]}（按当前 token 用户过滤）
- GET  /api/ui/schema      出参{appName,nav,pages}
- GET  /api/stats/overview 出参{total_detections,today_detections,grade_distribution,weekly_trend}
- GET  /api/stats/user/{user_id} 出参{total_detections,grade_distribution,confidence_trend}
④ 哈希链契约（你实现）：区块{index,timestamp,prev_hash,data_hash,hash}；data_hash=sha256(json(payload))；hash=sha256(index+timestamp+prev_hash+data_hash)；创世 prev_hash="0"*64

【数据库 Schema 建议】
users(id INTEGER PK, username TEXT UNIQUE, password_hash TEXT, role TEXT DEFAULT 'user', created_at TEXT);
detections(id TEXT PK, user_id INTEGER FK NULL, image_hash TEXT, class_id INT, class_name TEXT, confidence REAL, bbox TEXT, trace_block_index INT, created_at TEXT);
hashchain(index INTEGER PK, timestamp REAL, prev_hash TEXT, data_hash TEXT, hash TEXT, payload TEXT);
