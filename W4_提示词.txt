【W3 已交付的接口契约③（必须严格对接）】
- 统一响应：{"code":0,"message":"ok","data":{...}}，业务数据在 data 字段。
- POST /api/auth/register  入参{username,password} 出参{user_id,username,token}
- POST /api/auth/login     入参{username,password}（OAuth2 form）出参{user_id,username,token}
- GET  /api/auth/me        出参{user_id,username,role}
- POST /api/auth/logout    出参{message}
- POST /api/detect         入参 multipart image 出参{class_id,class_name,confidence,bbox,trace_id,user_id}
- POST /api/trace          入参{trace_id,payload} 出参{block_index,hash,prev_hash,timestamp,trace_id}
- GET  /api/trace/{id}     出参{valid,chain:[{index,timestamp,prev_hash,data_hash,hash,payload}]}
- GET  /api/detections     出参[{id,user_id,image_hash,class_id,class_name,confidence,bbox,trace_block_index,created_at}]
- GET  /api/ui/schema      出参{appName,version,theme,nav,pages}
- GET  /api/stats/overview 出参{total_detections,today_detections,grade_distribution:[{name,value}],weekly_trend:[{date,count}]}
- GET  /api/stats/user/{user_id} 出参{total_detections,grade_distribution:[{name,value}],confidence_trend:[{date,avg_confidence}]}
- GET  /models/{filename}  静态文件路由，可直接拿到 models/test_metrics.json、models/training_curves.png 等 W2 产物

【W3 已交付的 UI Schema 结构（必须按此渲染）】
文件位置：src/backend/ui_schema.json，运行时通过 GET /api/ui/schema 获取。
- appName：应用标题，用于导航栏和浏览器标题。
- version：版本号。
- theme：{primary,secondary,background,text} 配色。
- nav：导航菜单数组，每项 {key,label,icon,path}。未登录时只显示公开项（/、/trace）。
- pages：页面配置对象，键为 nav.key，值为 {title,widgets}。widgets 中的 type 决定渲染组件：
  - stat-card：统计数字卡片（读取 data[metric]）
  - pie-chart：等级分布饼图（读取 data[metric]）
  - line-chart：趋势折线图（读取 data[metric]）
  - image-upload：图片上传组件，调用 POST /api/detect
  - result-card：检测结果展示卡片
  - data-table：数据表格
  - trace-input：trace_id 输入框，调用 GET /api/trace/{id}
  - trace-chain：哈希链时间线
  - user-info：当前用户信息
  - json-viewer：JSON 展示/编辑器
  - image：静态图片展示（src 来自 /models/...）
  - metrics：指标 JSON 展示（src 来自 /models/...）
